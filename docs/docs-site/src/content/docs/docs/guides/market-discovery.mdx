Find active prediction markets on Polymarket — no authentication required.

## Search markets

```bash
polygolem markets search --query "btc 5m" --limit 10
polygolem markets search --query "ethereum" --limit 5
```

## Discover crypto markets

Find active crypto prediction markets with asset and interval filtering:

```bash
# Bitcoin 5-minute up/down markets
polygolem markets crypto --asset BTC --interval 5m --limit 10

# Ethereum markets with CLOB price enrichment
polygolem markets crypto --asset ETH --interval 15m --enrich

# All crypto markets
polygolem markets crypto --limit 50
```

Returns token IDs, outcomes, prices, and optionally live CLOB price/spread data.

### Resolve the current window directly

For time-windowed markets (5m, 15m, 1h, 4h), use deterministic slug resolution
instead of search — faster and immune to search index lag:

```bash
# Exact current BTC 5m window
polygolem markets crypto-window --asset BTC --interval 5m

# With live CLOB price and spread
polygolem markets crypto-window --asset ETH --interval 15m --enrich
```

This hits the event directly by its deterministic slug
(`btc-updown-5m-<unix_timestamp>`) and returns the active market with token IDs.

### List all 6 active 5-minute crypto markets

Scan every supported crypto asset and return the current 5m window for each:

```bash
# All 6 markets at once
polygolem markets crypto-5m

# With live CLOB price and spread (slower, one API call per market)
polygolem markets crypto-5m --enrich
```

Assets scanned: BTC, ETH, SOL, XRP, BNB, DOGE, HYPE.
Returns token IDs, outcomes, condition IDs, and window boundaries for every
active market in a single JSON response.

### Stream crypto markets

Subscribe to live WebSocket events for crypto markets:

```bash
polygolem stream crypto --asset BTC --interval 5m --max-messages 100
polygolem stream crypto --asset ETH --custom-features
```

### Get crypto market snapshots

Fetch current CLOB snapshots (price, spread, midpoint, tick size) for crypto markets:

```bash
polygolem prices crypto --asset BTC --interval 5m --limit 10
polygolem prices crypto --asset SOL --limit 5
```

## Browse Polymarket categories

Polymarket's website category nav is not exposed as one public category-list
API. Polygolem keeps a small curated mapping and fetches category feeds through
Gamma `events/keyset` where a stable `tag_slug` exists:

```bash
# List curated polymarket.com categories and route/feed metadata
polygolem markets categories --json

# Fetch the Mentions feed (maps to Gamma tag_slug=tweets-markets)
polygolem markets categories --slug mentions --events --limit 10 --json

# Fetch the World Cup feed (maps to curated World Cup tags)
polygolem markets categories --slug world-cup --events --limit 10 --json
```

`Breaking` is listed as route-only because no stable Gamma `tag_slug` was found
for it. `All` and `Trending` use the plain Gamma `events/keyset` feed without a
`tag_slug`. Source: `pkg/gamma/categories.go:17` to `pkg/gamma/categories.go:35`,
`internal/gamma/categories.go:36` to `internal/gamma/categories.go:68`.

## Get market details

```bash
polygolem markets market --id "0xbd31dc8a..."   # by Gamma ID
polygolem markets market --slug "will-btc-..."    # by slug
```

## Enrich a market

Joins Gamma metadata with CLOB data in one call:

```bash
polygolem markets enrich --id "0x..."
```

Returns: question, outcomes, prices, best bid/ask, spread, volume, tick size, fee rate, neg risk status, orderbook snapshot.

## Gamma API Methods

| Method | Description |
|--------|-------------|
| `Markets` | List markets with filters |
| `Events` | List events with filters |
| `Search` | Cross-entity search (markets, events, profiles, tags) |
| `Tags` | List tags, get by ID/slug, related tags |
| `Series` | List series, get by ID |
| `Teams` | List sports teams |
| `Comments` | List comments, get by ID/user |
| `Profiles` | Get public profile by wallet |
| `SportsMarketTypes` | List valid sports market types |
| `MarketByToken` | Resolve market from CLOB token ID |
| `EventsKeyset` / `MarketsKeyset` | Keyset pagination variants |
