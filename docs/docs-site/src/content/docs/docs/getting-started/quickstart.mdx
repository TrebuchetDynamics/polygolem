Three realistic workflows to get you productive.

## 1. Find and inspect a market

```bash
# Search for active BTC markets
polygolem markets search --query "btc 5m" --limit 5

# Discover crypto markets with enrichment
polygolem markets crypto --asset BTC --interval 5m --enrich

# Resolve the current window directly (deterministic, no search)
polygolem markets crypto-window --asset BTC --interval 5m --enrich

# Get full market details
polygolem markets market --id "0xbd31dc8a..."

# Get everything at once — Gamma metadata + CLOB tick size, fee, orderbook
polygolem markets enrich --id "0xbd31dc8a..."

# Live stream crypto market events
polygolem stream crypto --asset BTC --interval 5m --max-messages 10

# Quick marketdata snapshots for crypto
polygolem prices crypto --asset ETH --limit 5

# List all 6 active 5m crypto markets
polygolem markets crypto-5m --enrich

# One-command paper trade on current window
polygolem sim trade --asset BTC --interval 5m --side up --size 1
```

## 2. Onboard your deposit wallet (required for trading)

Polygolem's only supported trading mode is **deposit wallet (type 3 / POLY_1271)**.
EOA, proxy, and Safe are blocked for new API users by CLOB V2.

```bash
# Get builder credentials (free) at polymarket.com/settings?tab=builder
# Then deploy, approve, and fund in one command:
SIGNER_PRIVATE_KEY="0x..." \
POLYMARKET_BUILDER_API_KEY="..." \
POLYMARKET_BUILDER_SECRET="..." \
POLYMARKET_BUILDER_PASSPHRASE="..." \
  polygolem wallet onboard --fund-amount 14 --confirm ONBOARD_WALLET --json

# Sync CLOB balance
polygolem exchange update-balance --asset-type collateral

# Check your balance
polygolem exchange balance --asset-type collateral

# Place an order
polygolem exchange create-order \
  --token "123..." \
  --side buy \
  --price 0.51 \
  --size 10 \
  --output json
```

## 3. Use as a Go SDK

```go
import "github.com/TrebuchetDynamics/polygolem/pkg/orderbook"

reader := orderbook.NewReader("")
book, err := reader.OrderBook(ctx, "token-id-here")
// book.Bids[0].Price = 0.51
// book.Asks[0].Price = 0.53
```
