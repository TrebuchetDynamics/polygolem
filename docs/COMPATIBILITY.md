## Normalized Error Kinds

| Kind | Meaning |
|---|---|
| `unknown` | Unclassified upstream error after redaction. |
| `rate_limited` | Upstream rate limit or too-many-requests response. |
| `geoblocked` | Upstream geoblock or restricted-jurisdiction response. |
| `auth_rejected` | Credential, API key, signature, or authorization rejection. |
| `tick_size_mismatch` | Order price does not align with the market tick size. |
| `market_closed` | Market is closed, resolved, or unavailable for new action. |
| `insufficient_funds` | EOA or deposit wallet balance is insufficient for the requested action. |
| `upstream_unavailable` | Upstream Polymarket service returned a 5xx/outage-style response. |
